# 转向退化定位与最小修复

## 结论

本轮确认的退化来源是Kev输入表示与选择提示的变化。候选精简时删除绝对转角 `turn_deg` 后，即便仍有 `signed_turn_deg` 和目标角误差，模型也经常对侧后方目标持续选择直行。恢复候选末尾的 `turn_deg`，并恢复历史版本优先减小当前目标航向误差的短提示，可明显改善这些状态的转向选择。没有调整运动模型、转角计算、速度阶段或进展监督默认参数。

这属于有受控回放支持的输入回归定位，不能据此断言所有导航问题都已解决，也不能认为数学上冗余的字段对该模型一定冗余。字段位置的回放表现不同，因此本次保留已验证的顺序。

## 角速度与角加速度

`jev_api/tools/navigation_motion.py` 的Kev分支采用 `sign(delta) * min(abs(delta), max_turn_rate_deg_s * t)`：最大角速度45度/秒，默认决策周期1秒，候选航向最多变化±45度。积分步长0.02秒。

没有角加速度上限或角速度状态；开始转向与停止转向时直接切换角速度，切换处没有有限的角加速度。不能将45度/秒称为角加速度，也不能把0.5秒速度过渡时间当作Kev转向加速时间。旧图使用相同45度/秒约束，故该参数没有发生导致本次退化的变化。此模型尚无实艇动力数据标定。
