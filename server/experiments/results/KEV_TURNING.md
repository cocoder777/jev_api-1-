# 受限转向实现与验证

当前Kev固定15节，16个候选改为**当前方向附近、本周期可达区间内的绝对航向**，不再覆盖全局360度。选项ID `heading_00`…`heading_15` 仅为本次请求的标识，动作解码从本次请求读取对应角度，不再依赖固定全局表。

## 参数与资料

尚无本艇船长、船型、推进形式、转向试验和初始艏向。公开资料不能据此推导唯一真实最大转向角速度。暂采用可配置的5度/秒作为明确标注的仿真假设；15节时恒定该角速度对应半径约88.43米，90度至少18秒。该数值不是文献测得的本艇性能，也不是IMO要求。

- [USV Yaw Modeling and Identification](https://arxiv.org/abs/2303.13064)以试验辨识转向模型参数。
- [IMO MSC.137(76)](https://wwwcdn.imo.org/localresources/en/KnowledgeCentre/IndexofIMOResolutions/MSCResolutions/MSC.137%2876%29.pdf)有特定船型/船长适用范围，并不提供本艇的统一角速度。

周期1秒时区间为当前方向±5度；周期0.2秒时为±1度。区间采样16项并保留直行。向内量化至0.01度避免越界，跨0/360度使用最短角差。静止时真实艏向不能靠调研获知，模拟器默认向东90度；实际报文服务需有效运动方向或显式配置实际初始方向，不能将目标方位用作艏向。

预测器与模拟器均采用同一角速度上限；未模拟角加速度、舵机迟滞、风流或艏向与地速方向差异，因此这是受限运动近似，不是已标定船体动力学。Jev/Julia未配置该上限时沿用旧模型。

## 提示词和注释字段

提示词中的speed_transition_s、course_transition_s已删除。速度响应参数仍用于内部启动/变速预测；Kev转向改用角速度上限，旧的固定0.5秒转向时间不再生效。

保持删除无运行依赖的total_waypoints与数值限速字段。arrival_radius_m和command_duration_s恢复为有意义的目标边界和预测时域字段。历史距离改由内部观测计算，即使继续精简模型state也不会触发该距离字段的KeyError。

局部候选的距离变化可能接近且短期都在远离侧后方目标，因此加入相对目标角、候选对目标角误差和左右转语义。仍由模型完整选择16项，不排序、代选或失败补选。所有模型输入浮点数保留两位小数。

## 已运行的验证

- 31项回归测试通过，包含动态候选、跨0度、量化后不越界、方向缺失报错、两位小数、删除可选提示词字段、初始方向与预测/模拟器角速度一致性。
- `kev-bounded-turn-5hz`：真实模型600步，0.2秒周期。全部候选在测量方向±1度，实际仿真最大角速度约5度/秒；通过首航点。该轮使用早期提示词，换向不佳，不能视为完整导航成功。
- `kev-turn-probe.json`：侧后方目标的单次模型试验，目标相对角约-146.31度，模型选择左转4.33度。
- `kev-bounded-turn-1hz`、`kev-bounded-turn-final`：中间提示词闭环试验，仍存在偏好直行或不必要转向；没有复用历史10/10结论。
- `kev-bounded-side-turn.jsonl`：最后左右转语义版本的连续50步侧后方目标试验，模型确实向左转，最后记录方向约50.33度（初始90度），但尚未转向目标，因此距离仍增加，未验证整条航线。

最新版本的完整导航效果仍需继续评估；当前确认的是物理转向限制和代码兼容性，不能将过去全局角度/快速转向的10/10成绩用于当前版本。

使用（无需重启Kev模型服务）：

```bash
.venv/bin/python server/experiments/simulate.py --backend kev --scenario crossing_km \
  --steps 10000 --dt 0.2 --max-turn-rate-deg-s 5 --initial-course-deg 90 \
  --output server/experiments/results/kev-local-turn-test
```

`--initial-course-deg 90` 仅为模拟器起点设置；原现场IP/端口保持原值。参数与启动说明另见 `server/KEV.md`。

最终真实UDP参数传递与停车短测通过，结果见 `kev-bounded-udp/summary.json`：0.2秒周期、5度/秒上限，收到29条控制和7条状态，非零速度动作正常，显式停止后实际降速并返回stopped。最新回归共31项通过。原现场IP/端口未改。
