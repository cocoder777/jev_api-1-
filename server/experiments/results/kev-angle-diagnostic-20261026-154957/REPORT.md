# 转角与P2→P3真实诊断

当前速度档位10、20、30、40、50节，到达半径100米，周期1秒，转向上限45度/秒。以首航点为内部原点，图像平移到旧图坐标以便对照。

本次将准备转角改为当前实测航向与当前目标到下一个航点方向的最小夹角：`abs((next_leg_bearing_deg - actual_course_deg + 180) % 360 - 180)`。`route_corner_deg`保留相邻计划航段夹角，仅用于对照。原计划P2转角138.18度，原代码已归入大于135度的10节档位，并非误判为锐角。

仅本次诊断将恢复失败上限从20设为10000次观测；距当前有限航段偏离800米或距目标比该目标的历史最近距离增加1000米后停车。正式服务仍保持20次恢复失败上限。调用真实本地CUDA Kev，没有模拟模型答案，没有跳过未访问航点。

- 全航线：360个采样，通过P1和P2，分别在30秒、183秒以10节入圈。P2最后一次进圈前观测：实测航向279度，下一段方位81.87度，实际转角162.87度，准备/实际速度均为10节。P2→P3阶段175次有效决策，173次直行、2次朝目标转向，最终偏离航段803.6米后确认停车。
- P2专项：从P2入航段上、距P2约150米处起跑，初始方向303.69度，原任务仅标记P1已完成。187个采样，10秒以10节进入P2到达圈。模型收到的航向量化到303度，下一段81.87度，夹角138.87度，准备速度10节。切换到P3后连续175次直行，偏离航段800.4米后确认停车。P3未到达。

结论：放宽早停后能够观察到P2转向失败；速度已经降至10节，当前证据指向大角度下模型持续选择直行。该结论不等于航线已通过，也不证明提前减速参数已实艇标定。
