# 恢复计划转角后的真实重跑

使用最新代码和本地CUDA Kev重跑用户原图的 crossing_km 航线。2000步上限、1秒周期、45度/秒转向假设、静止向东起航。内部以首航点为原点，图像平移到旧图坐标。没有修改生产策略，没有模拟模型答案或跳过航点。

本次仅沿用上一轮诊断的放宽早停：恢复无改善上限设为10000轮，距当前航段达到800米或距目标比此前最近距离增加1000米后停车。正式服务默认20轮无改善保护保持原值。

实际208个采样、207秒仿真、约51.82秒现实耗时。30秒以10节进入P1到达圈；P2未到达。巡航最高50节，19条指令使用50节，187条使用10节，最后2条为0节。最终距P1→P2航段802.47米，已确认停车。没有记录航点圈内超速。

## 与用户旧图的结果比较

旧图为保存的历史真实结果，本次未重新执行历史模型输入。旧版固定15节、到达半径50米，通过4/10；最新版速度10/20/30/40/50节、到达半径100米，本次通过1/10。这些条件及输入结构均有差异，不能据此单独断言某一项变更造成退化。

- 旧版P1→P2：148次决策，139次直行、9次朝目标转向；到达该点前采样距参考航段最大约21.55米。
- 最新P1→P2：停车前记录到176次有效决策，172次直行、3次朝目标转向、1次反向；最后可执行记录距航段约797.33米，下一次触发诊断停车的观测距航段802.47米。
- 最新S→P1：轨迹距参考段最大约9.83米，直线满速与进圈减速均生效。

结论：用户观察到的前段退化得到本次重跑支持。已恢复的计划角和10节减速没有恢复旧版的转向表现。后续应以旧图前四航点为回归基线，固定观测逐项对照提示词、状态字段和候选组织，定位方向选择退化来源，避免直接叠加规则后宣称解决。
